# 路线图

状态：`✅ 完成` · `🚧 进行中` · `⏳ 计划` · `❌ 不做/不符合边界`

## P0 · 验收与正确性

- [ ] 真机（Android 14–16）安装、启动、导航
- [ ] 真实 DeepSeek Key：测试连接 → 单轮 → 多轮 → 停止/重生成
- [ ] 401/404/429/断网/空回复的真实 UI 表现
- [ ] Shizuku：配对、授权、`id` 验证、命令执行
- [ ] 无障碍：启用服务、UI 树、点击/输入校验、受保护窗口拒绝
- [ ] 进程被杀后任务暂停与恢复流程
- [ ] Room v1 → v2 升级实测

## P1 · 体验与质量

- [ ] 剩余页面资源化：MCP、技能、诊断、工作区、记忆、日志、设备
- [ ] core 错误改为 `LlmErrorKind`，由 UI 本地化
- [ ] Compose UI 测试：首次配置、发送/停止/重试、语言切换、旋转、键盘
- [ ] 长会话与大量消息的滚动/内存测试
- [ ] 截图与产物通过 FileProvider 分享
- [ ] 每个模型独立重试策略与费用上限
- [ ] 一键自检与脱敏诊断报告导出
- [ ] Android 14+ 前台服务/后台限制复核

## P2 · 能力扩展

- [ ] stdio MCP（在明确存在运行时的情况下）
- [ ] 可选 Python/Node 运行时（ABI、依赖、沙箱检测）
- [ ] 语义记忆（可插拔 Embedding；无模型时回退关键词）
- [ ] 视觉闭环（截图 → 结构化动作 → 再观察），保持每步校验
- [ ] 模型费用估算（仅使用服务端返回的 token）
- [ ] 定时任务的 WorkManager 前台化与 Doze 适配
- [ ] 性能：启动耗时、内存、日志轮转

## 非目标

- Root 或绕过系统沙箱
- 绕过锁屏、生物识别、权限对话框、应用访问控制
- 未认证的远程控制接口
- 伪造工具输出或把编译通过当作真机可用
