# Markdown Report

Use this skill when the user wants a written deliverable.

Structure:
1. Title (the user's goal, not a generic heading).
2. Date and data sources actually used.
3. Findings, each with the evidence it came from (tool name and key values).
4. Open questions or failures.
5. File references produced during the task.

Rules:
- Write the file with `file.write` under `exports/<slug>-<timestamp>.md`.
- Do not add sections you have no data for.
- Do not claim a source you did not actually query.
