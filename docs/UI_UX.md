# UI/UX 优化说明

## 1. 信息架构

一级导航从 14 个平铺入口收敛为 5 个高频 Tab：

| Tab | 内容 |
| --- | --- |
| 对话 | 默认入口；普通聊天与 Agent 模式 |
| 任务 | Agent 任务的计划、工具、事件、检查点、产物 |
| 终端 | 应用 Shell / Shizuku 双模式 |
| 工作台 | 设备与系统状态、最近任务、快捷入口 |
| 我的 | 模型、语言、设备控制、MCP、技能、记忆、工作区、日志、诊断、高级设置 |

MCP、技能、模型、诊断、日志、权限与高级设置通过「我的」或抽屉进入，避免首屏认知负担。

## 2. 首次启动

`欢迎 → 选择服务商 → API Key → 模型 → 测试连接 → 保存并开始聊天`。

- Shizuku 与无障碍不阻塞首次对话。
- 服务商预设自动带出官方地址和推荐模型。
- Key 支持显示/隐藏，安全存储。
- 测试连接分阶段展示，失败时给出具体阶段与技术细节。
- “暂时跳过”允许先浏览应用，但聊天前需配置模型。

## 3. 对话界面

- 顶部：普通对话 / Agent 模式、历史会话、新建会话。
- 模型状态行：当前服务商 · 模型；未配置时显示红点与“添加模型”。
- 消息区：用户/助手气泡、Markdown、代码块、复制、重新生成。
- 流式输出：草稿单独渲染，输入框固定在滚动区外，避免布局跳动。
- 输入框：多行自适应、键盘避让、发送/停止按钮切换。
- 错误：显示“API Key 无效 / 模型不存在 / 网络失败”等可操作原因，并提供重试与打开模型设置。
- Agent 模式：输入后创建独立任务，显示“查看任务”卡片，执行过程在任务页查看。
- 历史会话：底部抽屉，支持切换和删除。

## 4. 模型管理

- 卡片展示：服务商、模型 ID、连接状态、已验证能力、最近测试时间、默认标记。
- 只有测试验证过的能力才显示；未验证不冒充支持。
- 操作：设为默认、测试连接、编辑、删除。
- 编辑页与首次配置共用同一套表单和客户端，避免“测试与聊天不一致”。

## 5. 视觉与适配

- Material 3，浅色/深色跟随系统或手动切换，Android 12+ 动态取色。
- 统一圆角、间距、状态色：正常（绿）、运行中（主色）、待确认（黄）、失败（红）、未验证（灰）。
- 中文文案按资源文件管理，主流程支持中英文切换。
- 长文本、长会话使用 LazyColumn 与局部刷新；流式草稿不写数据库。
- 关键按钮保留足够点击区域；图标带 contentDescription。

## 6. 状态与错误原则

- 每个请求都有确定的终态：完成、失败、停止或超时。
- 不存在无限 Loading：空回复、流式中断、鉴权失败都会结束并显示原因。
- 工具审批超时视为拒绝，不会默认放行。
- 会话生成中禁止并发发送，避免竞态与重复写入。
- 应用被杀后进行中的任务标记为暂停，由用户显式恢复。

## 7. 国际化完成度（如实说明）

已完成资源化并支持中英文切换：

- 底部导航、抽屉、对话、历史会话、首次配置、服务商表单、连接测试、模型卡片、我的、语言切换。
- 任务、终端、设置的主要标题与按钮已中文化（部分旧描述仍为英文）。

仍存在的遗留：

- 部分 core 层错误提示直接返回中文，英文界面下不会自动翻译。
- 尚未做屏幕旋转、字体放大、横屏的自动化 UI 测试。
