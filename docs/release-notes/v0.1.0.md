## Mobile Agent v0.1.0（实验版）

运行在 Android 手机上的原生 AI 智能体：能聊天，也能在权限策略约束下真正执行任务。

### 本版亮点

- **DeepSeek 修复**：修复工具 function name 含点号导致每次请求 400 的阻断性缺陷；普通聊天不再发送任何工具。
- **聊天 / Agent 分离**：普通对话不依赖 MCP、Shizuku、无障碍；Agent 模式才进入规划与工具链。
- **模型向导**：7 个服务商预设、Key 加密存储、六阶段连接测试（必须收到真实文本）。
- **可恢复任务**：每次工具调用后落检查点；进程被杀后任务暂停，恢复前要求校验副作用。
- **中文主流程 + 5 个一级 Tab**，支持简体中文 / English 切换。

### 安装

1. 下载下方 `mobile-agent-v0.1.0-debug.apk`（Debug 签名，仅供测试）。
2. 安装：

   ```bash
   adb install -r mobile-agent-v0.1.0-debug.apk
   ```

3. 首次启动选择 DeepSeek → 填入 API Key → 保留 `deepseek-flash` → 测试连接 → 保存并开始聊天。
